# UraPress WordPress-Theme

Eigenes, schlankes News-Theme für urapress.ch (Logo-Variante C, Rot/Anthrazit, Source Sans 3).

## Installation
- **Plesk:** WP Toolkit → urapress.ch → Themes → „Theme hochladen“ → `urapress-theme.zip` → Aktivieren
- **oder WordPress:** Paraqitja (Design) → Temat → Shto të re → Ngarko temë

## Was das Theme mitbringt
- Startseite: Hauptmeldung + 4, „Të fundit“, danach ein Block pro Rubrik (nur wenn sie Artikel hat)
- Rubriken in der Reihenfolge: Zvicër, Diaspora, Kosovë, Shqipëri, Maqedoni e Veriut, Mal i Zi,
  Lugina e Preshevës, Bota, Ekonomi, Sport, Kulturë & Showbiz (erscheinen im Menü automatisch,
  sobald die Kategorie existiert; ein eigenes Menü unter Design → Menüs ersetzt das)
- Artikel: Lead (Auszug), Bildlegende mit „AI“-Kennzeichnung bei „Foto ilustruese (AI)“,
  Quellen-Box, Teilen per WhatsApp/Facebook/X, „Lexo edhe“
- Datum/Zeit immer auf Albanisch, Open-Graph-Tags für schöne WhatsApp-Vorschauen
- Widget-Bereiche: Seitenleiste, Werbung auf der Startseite
